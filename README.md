# OSSign Information
## What's this?
This is a repository used for creating signed binaries for the [fam007e/SecurePasswd_MGMT](https://github.com/fam007e/SecurePasswd_MGMT/) project.

## Where are the signed binaries published?
The signed binaries are published by the author on [fam007e/SecurePasswd_MGMT](https://github.com/fam007e/SecurePasswd_MGMT).

You can find the latest workflow runs for the build and signing process in the [Actions tab](https://github.com/ossign/fam007e--securepasswd_mgmt/actions).
